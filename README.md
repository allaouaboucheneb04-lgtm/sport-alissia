# Suivi Alissia

Application web mobile/PWA hors ligne pour suivre le programme alimentaire et la fiche de suivi.

## Installation locale
Les fichiers peuvent être ouverts sur ordinateur, mais les fonctions PWA/service worker nécessitent un serveur HTTP(S).

## Publication
Publier le dossier sur GitHub Pages, Netlify ou tout autre hébergeur HTTPS.

## Installation sur iPhone
1. Ouvrir l’URL avec Safari.
2. Partager.
3. Sur l’écran d’accueil.
4. Ajouter.

## Données
Les données sont stockées dans localStorage sur l’appareil. Utiliser Réglages > Exporter les données pour sauvegarder l’historique.
